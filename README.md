# 🎨 小小艺术家 · 论坛风实拍效果图生成器

一个给 **4-5 岁小朋友** 用的创意美术课效果图生成小工具。

你（老师/家长）在网页上填 5 个简单问题 → 程序调用 AI 生图接口 → 自动产出 **8 张「论坛风实拍效果图」**（像家长/幼教在小红书、育儿论坛随手拍分享的真实作品照），全部适配幼儿动手能力（只做撕、贴、涂、点；不要求精细剪纸或塑形）。生成后可一键「保存主题」到云端，形成历史记录，随时查看或重新修改。

## 💾 主题保存与历史记录（新）

- 生成完成后，点 **💾 保存主题** 即可把这次结果（含 5 个参数与 8 张图）保存。
- 保存采用「**云端 + 本机镜像**」双写：
  - 服务端会把记录写入 `data/history.json`；
  - 同时浏览器 `localStorage` 也存一份完整记录（含图片的远程地址）。
- 点顶部 **📚 历史主题** 查看所有已保存主题（云端与本机合并展示）：
  - **重新修改**：把当时的 5 个参数填回问卷，改一改再生成。
  - **查看**：直接回看这套效果图。
  - **删除**：移除某条历史（云端/本机分别处理）。

### 持久化与回退说明（很重要）
- 每条图片结果都额外保留了**混元返回的原始远程地址**（`remote_url`）。当服务端本地下载的图因重启/重部署丢失时，前端会自动回退到远程地址，保证图还能看。
- 部署在 **Render 免费版** 时，服务端文件系统是临时性的，每次重新部署都会清空 `data/history.json` 和服务端图片。因此：
  - 你**本机浏览器**里的历史镜像不受服务器重启影响，照常可用（推荐日常用这个）；
  - 若要做到「换设备也能看」的永久云端历史，需要把存储换成熟练的数据库 / 挂载磁盘（Render Disk 或外部对象存储），这属于付费/额外配置项。

## 本地运行（Windows，照做即可）

> 需要本机已装好 Python 3.10+。没有的话先装一个。

**第 1 步：准备生图 Token（最重要）**

程序靠一个「生图 Token」调用 AI。获取方式：
- 在你的 WorkBuddy 里打开「多模态内容生成」技能，或用 `connect_cloud_service` 拿到 `tempToken`（形如 `tk_xxxx`）。
- 把拿到的 token 存成文件：`art-class-generator/token.txt`，里面只写这一行 token，不要加别的。

> 注意：这个 token 是会话级的，约 15 小时过期。过期后重新拿一个新的，覆盖 `token.txt` 即可。

**第 2 步：安装依赖**

```bash
cd art-class-generator
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

**第 3 步：启动**

```bash
python app.py
```

终端会显示 `Running on http://127.0.0.1:5000`。浏览器打开这个地址即可。
点「不想填？直接看示例效果」可一键看样例；或自己填 5 个问题点生成。

## 部署成「可分享的公开链接」（推荐 Render，免费）

这样别人点开链接就能直接用，不用装任何东西。

1. 把这个仓库推到你的 GitHub（见下方）。
2. 打开 https://render.com ，用 GitHub 登录。
3. 点 **New + → Web Service → 选这个仓库**。
4. 部署配置会自动读取 `render.yaml`（构建命令、启动命令都已写好）。
5. 在 Render 的环境变量里加一项：
   - 名称：`BUDDY_CLOUD_TOKEN`
   - 值：你的生图 token（`tk_xxxx`）
6. 点 Deploy，几分钟后拿到一个 `https://xxxx.onrender.com` 的公开链接，发给谁都能用。

> token 只存在服务端，访问网页的人看不到，安全。
